# Cloud.Nails

Website giới thiệu dịch vụ chăm sóc móng, bộ sưu tập và đặt lịch của Cloud.Nails.

- Website: [`outputs/nail-salon/dist/index.html`](outputs/nail-salon/dist/index.html)
- Hướng dẫn: [`outputs/nail-salon/README.md`](outputs/nail-salon/README.md)
- Kết nối đặt lịch sau này: [`BOOKING-INTEGRATION.md`](outputs/nail-salon/BOOKING-INTEGRATION.md)

Website dùng HTML, CSS và JavaScript thuần; không cần cài dependency hoặc build. Mở `outputs/nail-salon/dist/index.html` để xem.

Luồng đặt lịch hiện tại là demo frontend, chưa gửi yêu cầu hoặc email thực tế.
